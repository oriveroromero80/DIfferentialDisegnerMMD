# Differential Designer MMD

Herramienta didáctica para diseñar un diferencial abierto de engranajes cónicos rectos.
Curso de Dibujo de Ingeniería · Proyecto final — Autor: Oswaldo Rivero-Romero.

- **Usar en línea:** abre la dirección de GitHub Pages de este repositorio.
- **Usar sin internet:** descarga `index.html` y ábrelo con doble clic en el navegador.

El diseño de cada estudiante se guarda en su propio navegador. Al terminar, descarga la bitácora en PDF desde el módulo «Bitácora».
